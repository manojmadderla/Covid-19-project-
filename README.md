# Covid-19-project-
🦠 COVID-19 Data Analysis using Python
📌 Project Overview

This project performs an exploratory analysis of COVID-19 data using Python. The notebook analyzes confirmed cases, deaths, and recovered cases across different regions/countries to identify trends and insights from the pandemic dataset.

The analysis leverages Pandas, NumPy, and Matplotlib for data cleaning, aggregation, and visualization.

🎯 Objectives
Analyze COVID-19 cases across different regions.
Identify regions with the highest and lowest confirmed cases.
Compare death counts among regions.
Examine recovery statistics.
Perform data cleaning and validation checks.

Python

NumPy
